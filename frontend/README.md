# MandiPulse frontend

Next.js dashboard for MandiPulse. See the [main README](../README.md) for what the project does and how to run it.

```bash
npm install
npm run dev   # http://localhost:3000 — expects the Django API on http://127.0.0.1:8000
```

Set `API_ORIGIN` to point the `/api/*` proxy at a different backend.
